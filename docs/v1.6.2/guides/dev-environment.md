# 개발환경 설정

Upbit API를 사용하기 위한 개발 환경 설정 가이드입니다. Python, Java, Node.js 환경에서 API를 호출하기 위한 기본 준비 과정을 안내합니다.

## 시작하기

Upbit API를 처음 사용하는 경우, 다음 순서로 진행하는 것을 권장합니다.

1. 사용할 개발 언어 선택 (Python, Java, Node.js)
2. 개발 환경 설정 및 필수 라이브러리 설치
3. API Key 발급 및 인증 방식 이해
4. REST API 또는 WebSocket 호출 테스트

## 언어별 개발 환경 설정

* [Python 개발 환경 설정](https://docs.upbit.com/kr/docs/dev-environment-python) — Python 설치, 가상 환경 구성, REST API 및 WebSocket 호출을 위한 라이브러리 설정
* [Java 개발 환경 설정](https://docs.upbit.com/kr/docs/dev-environment-java) — JDK 및 개발 도구 설정, HTTP 클라이언트 라이브러리 구성, API 호출을 위한 기본 환경
* [Node.js 개발 환경 설정](https://docs.upbit.com/kr/docs/dev-environment-nodejs) — Node.js 설치, 패키지 관리, REST API 및 WebSocket 호출을 위한 라이브러리 설정
