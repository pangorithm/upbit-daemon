# 개인지갑 주소 등록

개인 지갑 주소를 업비트의 출금 허용 주소로 등록하는 방법을 안내합니다.

## 개인 지갑 주소 등록

업비트에 등록할 개인지갑을 선택 후 환경설정을 진행해주세요. (예시: 메타마스크)

1. 크롬 확장프로그램에서 설치할 개인지갑을 검색하여 설치합니다.
2. 크롬 브라우저에 개인지갑 설치 후 지갑을 생성합니다.
3. 개인지갑이 생성되었다면, 업비트 PC 웹에 로그인한 후 [마이페이지 > 주소관리 > 개인지갑 주소 관리](https://upbit.com/mypage/customer_info/personal_wallet)로 이동해 등록할 개인지갑을 선택합니다.
4. 등록하려는 본인 소유의 개인지갑 정보를 입력한 후, 유의사항과 개인정보 수집·이용 동의 내용을 확인하고 체크박스를 선택해 동의해 주세요. 이후 2채널 인증을 완료하고, 지갑 소유 확인을 위한 서명을 완료하면 개인지갑 주소 등록이 완료됩니다.

## 출금허용주소 등록

업비트 PC 웹에 로그인한 후, [마이페이지 > Open API 관리](https://upbit.com/mypage/open_api_management)에서 [디지털 자산 출금주소 관리 탭]으로 이동합니다. [출금허용주소 등록하기 → 주소 추가] 버튼을 클릭합니다.

'지갑종류'에서 [개인지갑]을 선택합니다. 그 후 등록할 개인지갑을 선택해 주세요.

## 인증 및 출금 주소 등록 완료

주소 등록 페이지에서 [확인] 버튼을 클릭한 후, '인증 대기' 화면에서 인증 대기 중인 주소를 확인할 수 있습니다. 오른쪽 상단의 [2채널 인증하기] 버튼을 클릭해 인증할 항목을 선택해 주세요. 인증이 완료되면 '디지털 자산 출금 주소 등록 성공' 팝업이 표시됩니다.

## 출금허용주소 삭제

[디지털 자산 출금 주소 관리](https://upbit.com/mypage/open_api_management?tab=fund_source) 메뉴에서 가능합니다.
